# Publication scope and provenance

This repository contains Jadebound-authored progression source, configuration, documentation and portable tests. It uses separate curated Git history so private operational history and machine paths are not copied to GitHub. All local projects, content, prototypes, checkpoints, builds and older history remain preserved separately.

This curated source update carries V3 domain/migration/persistence, the corresponding actor and test support, optional original-character movement integration code and the project input conflict fix. It does not include the private gameplay maps, executable or operational harnesses. Independent checks of this exact source export include five portable suites, a fresh editor-module compile and four pure V3 codec tests; see [VALIDATION.md](VALIDATION.md). The privately tested package remains separate gameplay evidence. No excluded assets or executable were added.

Excluded: binary Content, Unreal template assets/animations, third-party art, Blender studies, proprietary reference images/PDF, real save files, resume receipts, travel URLs, logs, reports, footage, archives, build outputs/caches, credentials, editor/MCP settings and machine-specific scripts. Asset provenance is not complete. Exclusions do not mean every template is forbidden: Epic Examples and other content have distinct terms under the [Unreal Engine agreement](https://www.unrealengine.com/eula/unreal), [Epic content agreement](https://www.unrealengine.com/eula/content) and [Fab terms](https://www.fab.com/eula). No asset redistribution clearance is inferred from private use or a successful build.

No additional open-source license has been selected. Original work and third-party work retain their respective rights. A public repository does not grant permission to relicense excluded assets; see [GitHub's licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).

The public native capture implementation remains byte-for-byte unchanged, with its output root under the project's Saved directory and existing admission/resource limits. Its adjusted path still needs independent gameplay qualification. The host descriptor continues to omit local editor tooling. LF normalization does not import private operational configuration.

The older public Actor difference was a supported-V2 forward-V3 save guard, not a machine-path rewrite. Current V3 admission supersedes that guard: it retains the writer lease, refuses canonical V4 entries, selects namespaces by presence and protects malformed or conflicting selected banks from older-format fallback. Retaining the obsolete V3-refusal literally would prevent current V3 reopening.

Development resume/travel tickets are bearer credentials within one running loopback server; Unreal may log URL options. Never publish actual tickets, receipts, user banks or logs. These tickets do not establish production identity, server-restart recovery or online readiness. Keep private history separate, inspect the exact public diff and scan the exact candidate before any publication.
